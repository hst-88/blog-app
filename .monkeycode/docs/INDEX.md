# 检后无忧 文档索引

检后无忧是体检后健康管理平台：管理端导入报告并配置套餐/号源，用户看报告、预约、问 AI、咨询医生，医生处理预警、随访和复查提醒。三端共用 `server` 内存 + `store.json`。
