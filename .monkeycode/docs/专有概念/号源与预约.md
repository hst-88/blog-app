# 号源与预约

所有上架套餐共用一份全局时段号源，存在 `store.appointmentSettings`：`slotCapacity`、`slots`、`closedDates`。

单日可约上限 = 每时段人数 × 时段数。状态为 `booked` 的预约占号，`cancelled` 不占。停约日期上 C 端不能下单。

管理端「号源设置」写入配置；C 端列表/详情读 `GET /appointments/availability?date=`；确认页 `POST /appointments` 做满号/停约/套餐下架校验。页面关系见 当前工作区 `/.monkeycode/docs/专有概念/页面职责与三端关联.md`。
